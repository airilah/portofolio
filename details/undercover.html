Portfolio Description for Undercover Bot

1. Project Overview

Undercover Mobile is a feature-rich social deduction game built with the Flutter framework. The project focuses on digitizing the traditional group gaming experience, eliminating the need for physical cards or a human moderator. Players are assigned secret roles (Citizen or Undercover) and must use verbal strategy and deduction to identify intruders through a dynamic voting system.

2. Planning and Requirements Analysis

  • Problem Analysis: Traditional social deduction games often struggle with manual role distribution and the requirement for a non-playing moderator.
  • Proposed Solution: Development of a "Digital Game Master" app that automates role assignment, word distribution, and game rules enforcement.
  • Target Audience: Board game enthusiasts and social communities seeking an interactive, portable group activity.
  • Tech Stack: Leveraging Flutter for a high-performance, cross-platform experience (Android & iOS) with a unified codebase.

3. System Design

  • Architecture: Implemented Clean Architecture combined with MVC patterns to ensure scalability and high code maintainability.
  • UI/UX Design: Crafted in Figma with a "Mysterious Dark" theme, utilizing card-based navigation for a seamless user journey.
  • Game Logic: Engineered a custom word-pairing algorithm to maintain game balance by providing semantically similar words to different roles.
  • Data Management: Utilized JSON structures to manage local word pools and player session data efficiently.

4. Development and Implementation

  • Frontend: Developed with Flutter (Dart), featuring optimized state management and custom animations for role reveals.
  • Backend & Logic: Integrated Python-based logic for advanced word management and victory condition validation.
  • Services: Incorporated Firebase for real-time data synchronization and user authentication features.
  • Core Modules: Developed "Pass and Play" local multiplayer support, automated voting ballots, and dynamic player profile tracking.

5. Testing Phase

  • Functional Testing: Rigorous validation of game mechanics, ensuring zero-error role distribution and accurate win-condition detection.
  • Compatibility Testing: Verified UI responsiveness across multiple aspect ratios on both Android and iOS devices.
  • User Acceptance Testing (UAT): Performed group-play simulations to refine game pacing and improve instruction clarity based on user feedback.

6. Deployment and Maintenance

  • Production: Compiled optimized production builds (.apk and .aab) for Google Play Store distribution.
  • Version Control: Hosted the complete source code on GitHub with comprehensive README documentation for open-source collaboration.
  • Sustainability: Established a modular update system to allow for easy additions of new word categories and game modes.

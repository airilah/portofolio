Portfolio Description for Analisis Saham Bot

1. Project Overview

Analisis Saham Bot is an automated stock analysis system powered by Python, designed to assist investors in making data-driven decisions. The system integrates traditional technical analysis with Artificial Intelligence (AI) to provide comprehensive market insights, including real-time chart pattern detection and news sentiment analysis, all delivered through a seamless Telegram Bot interface.

2. Planning and Objectives

  • Problem Statement: Investors often struggle to monitor hundreds of stocks manually and filter relevant news for quick fundamental and technical assessments.
  • Project Goal: To create an automated "Analyst Assistant" capable of scanning the market and delivering ready-to-use reports instantly.
  • Core Objectives: Automation of technical indicator calculations, integration of AI-driven sentiment analysis, and automated generation of price charts.
  • Target Platform: Telegram, chosen for its speed, accessibility, and robust support for media-rich bot interactions.

3. System Design

  • Modular Architecture: The system is designed with a modular approach, separating concerns into specific scripts: data.py (data fetching), indicators.py (mathematical logic), and ai_model.py (NLP processing).
  • Data Flow Pipeline: Market data extraction (API/Scraping) → technical indicator processing → AI sentiment evaluation → chart visualization → automated notification.
  • Integration Logic: Designed to process complex financial data and convert it into simplified, actionable insights for the end-user.

4. Development and Implementation

  • Core Engine: Developed using Python with Pandas for high-performance data manipulation and Matplotlib for financial chart visualization.
  • AI Sentiment Module: Integrated Large Language Models (LLM) through the ai_model.py module to summarize business news and determine market sentiment (Positive/Neutral/Negative).
  • Quantitative Features: Built a backtest.py system to validate trading strategies against historical data, ensuring strategy reliability.
  • Real-time Scanning: Engineered a market scanner that filters emits based on specific technical criteria in seconds.

5. Testing Phase

  • Algorithm Validation: Rigorous cross-checking of technical indicator values (RSI, MACD, etc.) against industry-standard trading platforms.
  • NLP Accuracy: Evaluated the AI's precision in classifying financial news and summarizing market reports.
  • Latency Testing: Measured the bot's response time during high market volatility to ensure timely alert delivery.

6. Deployment and Monitoring

  • Execution Environment: Deployed on a Cloud VPS using Python virtual environments to ensure dependency consistency.
  • Automation: Configured main.py to run continuously, monitoring the Indonesia Stock Exchange (IDX) during market hours.
  • Error Handling: Implemented robust logging to monitor API connection health and automated recovery for data fetching tasks.

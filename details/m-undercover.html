Portfolio Description for Undercover Mobile

1. Project Overview

Undercover Mobile is a mobile-based social deduction game developed using the Flutter framework. The project aims to transform conventional card/board games into a seamless digital experience. Players are assigned one of two roles (Citizen and Undercover) and must engage in discussions to eliminate intruders through a strategic voting system.

2. Planning and Requirements Analysis

  • Problem Analysis: Physical social deduction games are often limited by the need for a human moderator and physical props.
  • Solution: Developing an application that acts as a "Digital Game Master" to automate role distribution and rules.
  • Target Audience: Social deduction game enthusiasts and communities looking for interactive group activities.
  • Technology Stack: Flutter was chosen for its cross-platform capabilities using a single codebase.

3. System Design

  • Architecture: Implemented Clean Architecture/MVC patterns to ensure high maintainability.
  • UI/UX Design: Designed in Figma with a dark theme to evoke a mysterious atmosphere and card-based navigation.
  • Role Logic: Developed a word-distribution algorithm to maintain game balance and difficulty.
  • Data Structure: Modeled player data and word pools using JSON format for efficiency.

4. Development and Implementation

  • Frontend: Built with Flutter (Dart), featuring custom animations and robust state management.
  • Backend: Developed server-side logic using Python for word management and victory validation.
  • Integration: Integrated Firebase for user authentication and real-time data synchronization.
  • Core Features: "Pass and Play" functionality, automated voting, and player profile management.

5. Testing Phase

  • Functional Testing: Verified that all game logic—including role assignment, elimination, and win/loss conditions—functions according to the rules.
  • UI/UX Testing: Tested display responsiveness across various screen sizes and operating systems (Android & iOS).
  • User Acceptance Test (UAT): Conducted simulations with real groups to gather feedback on game flow and the clarity of instructions.

6. Deployment Stage

  • Production Build: Compiled the application into .apk and .aab formats for Android and prepared certificate signing for iOS.
  • Distribution: Uploaded the codebase to GitHub as an open-source portfolio and prepared for potential Google Play Store release.
  • Maintenance: Provided comprehensive code documentation on GitHub to facilitate future updates and community contributions.
